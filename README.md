
# 🚀 Medicitas

**Medicitas** es mi gran proyecto personal, una aplicación web Full Stack diseñada para explorar y mejorar la gestión e información relacionada con el ámbito de la salud, ofreciendo una experiencia moderna, accesible y centrada en el usuario.

⚠️ **Nota:** Este proyecto utiliza datos de prueba, por lo que no representa información real.

---

## 🧠 Objetivo del proyecto

Este proyecto nace con el objetivo de aplicar, aprender y consolidar conocimientos en desarrollo web moderno, combinando un backend robusto con un frontend dinámico y escalable.

---

## 🛠️ Tecnologías utilizadas

### Backend
El backend está desarrollado con:

- Node.js
- Express
- API REST en formato JSON

### Herramientas y arquitectura backend:
- 🔐 Autenticación con JWT
- 🧂 Encriptación de contraseñas con bcrypt
- 🧠 Middlewares para control de acceso y seguridad
- 🗄️ Prisma ORM para gestión de base de datos
- 🐘 PostgreSQL como base de datos relacional
- 🧩 Arquitectura basada en controllers y services

---

### Frontend
El frontend está desarrollado con:

- React (JavaScript)

### Características del frontend:
- ⚛️ Uso de hooks como `useEffect`
- 🔄 Manejo de estados para reactividad de la aplicación
- 📱 Diseño totalmente responsive
- 🔐 Decodificación y manejo de autenticación
- 🎨 Interfaz enfocada en la experiencia de usuario
